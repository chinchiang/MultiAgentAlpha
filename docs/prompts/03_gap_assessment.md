# Prompt 3：對現況做六層差距評估

類別：落地評估

```
請依 docs/appendix-d-maturity.md 的 60 題問卷，對本組織目前的程式碼審查流程做差距評估。你可以讀取的證據：本 repo 的 .github/workflows/、CI 設定、任何安全工具的設定檔，以及我在對話中提供的說明。規則：

1. 每題給 0 到 4 分，並在旁邊寫「證據」：你看到了哪個檔案或哪句說明。沒有證據的題目給 0 分並標「無證據」，不要推測。
2. 依六層彙總得分與百分比，套用附錄D 的解讀。
3. 對每一層得分最低的兩題，各寫一段「最小可行的下一步」，引用報告第十部對應的治理建議編號（G-1 到 G-13）。
4. 若組織有上海或重慶廠區，另外對第 26 章的 CN-1 到 CN-4 做是／否／不適用的評估，單獨列表。
5. 輸出為 docs/assessment-<日期>.md。

產出物：docs/assessment-<日期>.md。
驗收：60 題都有分數與證據欄；六層彙總表齊全；CN 條目單獨成表。
```
