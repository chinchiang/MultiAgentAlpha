# 附錄E　落地 Prompt 套件（Claude Code + GitHub，8 組）

三類、八組，每組可單獨執行，不假設前一組已跑過。使用方式：在目標 repo 開啟 Claude Code，貼上該組 prompt。每組都以「產出物」與「驗收條件」結尾，讓執行者知道何時算完成。

| 組 | 類別 | 名稱 |
|---|---|---|
| 1 | repo 化與維護 | 把本手冊 repo 化並建立版本控制 |
| 2 | repo 化與維護 | 每季更新 pinned ground truth 與來源查證 |
| 3 | 落地評估 | 對現況做六層差距評估 |
| 4 | 落地評估 | 以真實三家族跑第一次校準並產出權重 |
| 5 | 落地評估 | 對現有 GitHub Actions 做 pwn request 與 SHA pinning 盤點 |
| 6 | 控制項即程式碼 | 把資料主權與家族多樣性規則寫成設定檔驗證 |
| 7 | 控制項即程式碼 | 固定 L0 工具版本並加上簽章驗證 |
| 8 | 控制項即程式碼 | 把治理建議 G-1 到 G-13 轉成可執行的合規檢查 |
