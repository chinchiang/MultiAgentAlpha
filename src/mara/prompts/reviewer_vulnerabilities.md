(CWE-89/78/94/1336), path traversal (CWE-22), SSRF (CWE-918), CSRF (CWE-352), insecure
deserialization (CWE-502), weak or misused cryptography (CWE-327/328/330), race conditions
(CWE-362), unsafe file upload (CWE-434), open redirect (CWE-601), IDOR (CWE-639),
unbounded resource allocation (CWE-770). XSS, CSP, auth, secrets, dependencies, workflows,
input validation and error handling are reviewed by other agents; only report them here if the
issue is cross-cutting and would otherwise be missed.
