# Calibration set

`samples/` holds five small, deliberately vibe-coded applications with `labels.json`
(dimension, CWE, file, line, quote, title) generated by `scripts/gen_calib_samples.py`.
They follow the defect profile reported for vibe-coded applications: placeholder logic,
unfiltered input, secret leakage. 51 labels in total.

`corpora/` (git-ignored) is where `scripts/fetch_calib_corpora.sh` places OWASP Juice Shop and
WebGoat. Those repositories have no machine-readable file:line vulnerability labels; a human
must author `labels.json` for them before they contribute to the metrics.

Run:

```bash
for s in calib/samples/*/; do
  mara review "$s" --provider mock --out calib-out/$(basename "$s")     # offline dry run
done
python scripts/calibrate.py --mode mock
```

Replace `--provider mock` with `--config config/mara.yaml` once the three family endpoints are
reachable, and pass `--mode live` to calibrate.py.
